MAN(1): COUNTEROPS — Restaurant Operations Platform
NAME

counterops — Store operations platform for cafes and restaurants (Sales, Kitchen, Inventory, AI Analytics).

SYNOPSIS

counterops [--pos-cashier] [--kitchen-kds] [--inventory-control] [--excel-sync] [--ai-rag] [--grab-mock]

DESCRIPTION

CounterOps is an end-to-end management platform designed for restaurant & cafe environments. Features full POS with table/takeaway modes, Kitchen display system (KDS) order tracking, table and zone management, recipe-based menu items, inventory movement alerts, automated Excel import/export, and a GrabFood mock order simulator for capstone demonstration.

AI ASSISTANT & TELEMETRY

Features an AI analytics assistant built with hybrid RAG, intent planning, streaming responses, and circuit breakers, falling back to governed PostgreSQL RPCs when external model keys are absent.

DUO DIVISION OF RESPONSIBILITIES
Tuấn Anh (Front-End): Built Next.js 14 App Router UI, cashier POS view, Kitchen KDS display, table layout grid, and shadcn/Tailwind responsive themes.
Hữu Hiệp (Database): Architected Supabase PostgreSQL schema, Row-Level Security (RLS) policies per organization/branch, pgvector embeddings, and negative stock triggers.
STACK & TESTING

Next.js 14, React 18, TypeScript, Tailwind CSS, Supabase (PostgreSQL + RLS + pgvector), Vitest (all tests + AI-specific suite).

git clone repo
MAN(1): VIETVOYAGE — AI Landmark & Travel Planning Platform
NAME

vietvoyage-travel — Computational-Thinking Vietnam travel planning backend API and web interface.

SYNOPSIS

travel-api [--landmark-ai] [--osm-pois] [--mongo-geo] [--trips-crud] [--rate-limit]

DESCRIPTION

VietVoyage provides an interactive travel planning interface and modular Flask backend API for discovering destinations across Vietnam. It features deep integration with OpenStreetMap (OSM) for provincial POI discovery (hotels, restaurants, attractions) and multi-day itinerary CRUD operations.

AI LANDMARK RECOGNITION & SECURITY

Users can upload photos to classify Vietnamese landmarks (e.g. Ha Long Bay, Da Nang, Hoi An). The backend features token-based authentication and smart IP rate limiting (10 req/60s window with automatic 5-minute unblocking and proxy detection).

DUO DIVISION OF RESPONSIBILITIES
Tuấn Anh (Front-End): Crafted travel website interface, multi-day itinerary builder, province POI explorer, and file-upload landmark prediction tester.
Hữu Hiệp (Database & API): Designed MongoDB document schemas (Users, APITokens, Trips, POIs, Provinces) with 2dsphere geospatial indexing, MongoEngine ODM, and rate limiting middleware.
STACK & ARCHITECTURE

Python (Flask modular blueprints), MongoDB with MongoEngine, OpenStreetMap GeoJSON, rate limiting security, and static API testing UI.
