# Portfolio RIEAD (Figma template)

Bản implement tĩnh của [Portfolio Template Riead trên Figma](https://www.figma.com/design/GrVjMDDvevMPScgdFzKj4Y/Portfolio-Template--Riead---Community-?node-id=0-1).

Nằm tách khỏi site gốc ở thư mục gốc `web-dev/`.

## Mở trang

```bash
cd portfolio-rieade
python3 -m http.server 8080
```

Mở `http://localhost:8080`.

## Code Connect

Lệnh `/figma-code-connect` cần Figma **Organization hoặc Enterprise** (Dev/Full seat).

Tài khoản hiện tại chưa đủ quyền nên không tạo được file `.figma.ts`.

Khi đã nâng cấp, chạy lại workflow Code Connect trên file Figma trên.

## Kiểm tra nhanh

```bash
node script.js
```
