# Soucha - Matcha & Coffee

A modern e-commerce web application for **Soucha**, specializing in high-quality matcha and coffee. Built with Next.js, Tailwind CSS, and Supabase.

## Features

- **🛍️ Complete Ordering Flow**: Browse the menu, customize drinks (size, powder, sweetness, ice, toppings), and manage the cart.
- **🛵 Delivery & Pickup**: Seamless checkout flow toggling between store pickup and delivery.
- **💳 VietQR Payment**: Automatically generates a VietQR code with the exact amount and order memo for quick transfers.
- **📦 Order Management**: Orders are stored securely in Supabase with Postgres.
- **💬 Telegram Integration**: Automatic order notifications sent directly to the store's Telegram via Bot API.
- **📱 Mobile-First UX**: Responsive design focusing on a native app-like experience for mobile users.

## Tech Stack

- **Framework**: [Next.js 14 (App Router)](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **State Management**: React Context & Reducers
- **Database**: [Supabase](https://supabase.com/) (PostgreSQL)
- **Deployment**: Vercel (Recommended)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set up Environment Variables:
   Create a `.env.local` file with the following keys:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=your-supabase-project-url
   SUPABASE_SERVICE_ROLE_KEY=your-supabase-service-role-key
   TELEGRAM_BOT_TOKEN=your-telegram-bot-token
   TELEGRAM_CHAT_ID=your-telegram-chat-id
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) to view the app in your browser.

## Database Schema (Supabase)

The `orders` table is used to store order data:

```sql
CREATE TABLE public.orders (
    id bigint generated by default as identity primary key,
    customer_name text not null,
    customer_phone text not null,
    fulfillment_type text not null,
    address text,
    pickup_time text,
    note text,
    items jsonb not null,
    total_price numeric not null,
    payment_method text not null,
    payment_status text default 'unpaid',
    status text default 'pending',
    created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
```
